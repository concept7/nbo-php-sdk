## Installation

You can install the package via composer:

```bash
composer require concept7/nbo-php-sdk
```

## Usage

```php
$skeleton = new NieuwbouwOffice\PhpSdk\NieuwbouwOffice();
echo $skeleton->echoPhrase('Hello, NieuwbouwOffice!');
```

## Testing
